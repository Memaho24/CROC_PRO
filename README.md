# CyberCroc 0.1— мастер-приложение для ПК клуба

## Запуск
- `CyberCroc.cmd` — графическая оболочка (кнопки, редактор конфигов, журналы).
- `Master.cmd` — то же самое в виде текстового меню (запрашивает права администратора).

Первый запуск: скопируйте `config.example.ini` в `config.ini` (или откройте вкладку «Файлы» в оболочке /
пункт [G] в Master.cmd) и впишите `BOT_TOKEN`, `CHAT_ID`, пути для бэкапа и т. д.

## Структура
```
CyberCroc.cmd / CyberCroc.ps1   GUI
Master.cmd                       консольное меню
config.ini  games.txt  apps.txt  office.txt  steam_path.txt   ваши настройки и списки
tools\                           все рабочие скрипты (Games, Apps, Backup, Cleanup, Deploy, Zapret, ...)
logs\                            журналы (создаётся сам)     BACKUP\  копии (создаётся сам)
legacy\                          старые скрипты (Start.cmd, Programs.cmd, _DEBUG_Office.cmd), не используются
```

## Что исправлено
1. **Master.cmd: аргументы.** `shift` не влияет на `%*`, поэтому каждому инструменту первым аргументом
   передавалось его же имя (в логе было `run Games.cmd Games.cmd`). Теперь аргументы собираются явно.
2. **Master.cmd: пункт [B] Telegram** вызывал несуществующий `TelegramTest.ps1` — файл добавлен.
3. **Master.cmd: экран очищался сразу** после PowerShell-инструментов, вывод не успевали прочитать — добавлена пауза.
   Журнал больше не затирается при каждом запуске (дописывается, ротация > 1 МБ).
4. **Master.cmd: Zapret** — раньше был только `status`; теперь подменю (установка, запуск, остановка, автозапуск, тест, удаление).
5. **Окончания строк.** Все `.cmd` были с LF — cmd.exe на таких файлах может терять метки `:LABEL` и `goto`.
   Теперь все `.cmd` — CRLF, все `.ps1` — UTF-8 с BOM + CRLF (без BOM Windows PowerShell 5.1 портит кириллицу;
   у `CyberCrocLogger.ps1` BOM не было).
6. **Дубли в корне.** Копии `Apps.ps1`, `Games.ps1`, `Backup.cmd` и др. лежали и в корне, и в `tools\`.
   Корневые копии работали неверно: `$Root = родитель папки скрипта` указывал уровнем выше. Оставлены только `tools\`.
   Старый корневой `Games.cmd` (без GameStatus) заменён версией из `tools\`.
7. **games.example.txt** начинался с текста `\xef\xbb\xbf` (испорченный BOM) — первая строка читалась как игра.
8. **Games.cmd:** шаблон нового `games.txt` был в устаревшем формате `steam;AppID;Name`; теперь формат
   `Name|PathCheck|Source|Launcher|AppID|MinVersion`.
9. `Fix.cmd` / `Fix-Master.ps1` больше не нужны (чинили окончания строк Master.cmd) — убраны.
10. `CyberCrocLogger.ps1`: две разные версии, нигде не используется — оставлена версия из `tools\`.

## Не проверялось
Скрипты проверены статически (метки, баланс скобок, кодировки, пути). Запуск на реальном Windows с Steam/Riot/
Telegram не выполнялся — проверьте сначала на одном ПК (CC07), затем раскатывайте.
