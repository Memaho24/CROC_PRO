tools\  Games.cmd Games.ps1 Notify.cmd Notify.ps1 Backup.cmd Cleanup.cmd Deploy.cmd

`config.ini` и `games.txt` — ваши файлы, не перезаписывайте. Рядом лежат `config.example.ini`
и `games.example.txt` — там показаны все новые параметры.

## Games (главное)
**Новое**
- Проверка версий/обновлений. Steam-игры (колонка AppID): читается `appmanifest_<AppID>.acf` во всех
  библиотеках Steam → статусы: не установлена / вышло обновление / обновление качается / файлы
  повреждены / установка не завершена. Не-Steam игры (колонка Path = .exe): читается версия файла и
  сравнивается с необязательной колонкой `MinVersion` → OUTDATED.
- Telegram: «ПК CC07 (№7)» + списком: какие игры не установлены, у каких вышло обновление,
  устаревшие, повреждённые. Приходит только если есть проблемы (`NOTIFY_ON_OK=1` — слать всегда).
- Предупреждение, если Steam не запущен (тогда он мог не узнать про обновления).

**Исправлено**
- `for /f` схлопывал пустые колонки `||` → AppID съезжал в колонку лаунчера, и автоустановка Steam
  не срабатывала никогда.
- `echo ... %G_PATH%` внутри `( )` ломался на путях с `)` (например `Program Files (x86)`).
- В Telegram уходила только сводка «OK 17/20» без названий.
- Лог перезаписывался при каждом запуске → теперь дописывается, ротация при > 1 МБ.

## Notify

## Backup
- Пути с пробелами (раньше список резался по пробелам).
- Дата через PowerShell (раньше `%DATE%` зависел от региональных настроек).
- Ротация: хранится `KEEP_BACKUPS` последних копий на каждый пункт (раньше диск заполнялся).
- `robocopy /XJ` (не ходит по junction), корректный корень диска, уведомление при ошибках.

## Cleanup
- `EMPTY_RECYCLE` читался, но не использовался — теперь работает (Clear-RecycleBin для всех дисков).
- Пути с пробелами; защита: корень диска, Windows, Users, Program Files, профиль — отказ.
- `DISM /resetbase` необратим (нельзя удалить установленные обновления) и очень долгий →
  выключен по умолчанию (`DISM_CLEANUP=0`, `DISM_RESETBASE=0`).
- Проверка прав, вывод «освобождено МБ».

## Deploy.cmd
- Ввод номера ПК: `04` (как в подсказке!) отклонялся, `08`/`09` считались восьмеричными.
- `echo ... (reboot needed)` внутри блока — синтаксическая ошибка на коде 3010.
- `choice /c r` не мог вернуть 2 → «любая другая клавиша» не работала; теперь R / Q.
- Проверка прав через `fltmc` (`net session` даёт ложный отказ при выключенной службе Server →
  бесконечный перезапуск).

## Master.cmd
- `fltmc` вместо `net session`, цвет/заголовок возвращаются после подскриптов, проверка наличия
  логов и папки tools, «RUN ALL» ждёт нажатия клавиши в конце, пункт [8] тест Telegram.

## Start.cmd (правки точечные, логика ваша)
- Та же ошибка с номером ПК (04 / 08 / 09).
- **Серьёзно:** после `shutdown /r /t 0` выполнение проваливалось в `:RemoveApp` с пустым именем →
  `Get-AppxPackage *""*` = все приложения. Добавлены `exit /b` и защита от пустого имени.
- Проверка прав перенесена в начало (режим не спрашивается дважды), `fltmc`.
- Финальный `choice /c rq`.

## Не менял, но стоит знать (Start.cmd)
- UAC выключен, брандмауэр выключен целиком, Windows Update отключён + удаляется SoftwareDistribution.
- `icacls D: /grant Everyone:F /T` + шара DataD: полный доступ всем к диску D.
- Пароль сертификата `bllbFjFj` лежит открытым текстом (в Start.cmd и Deploy.cmd).
- Настройки `HKCU` (тема, панель задач, меню) применяются к учётке, из-под которой запущен скрипт.
  Если это не ARM — у ARM они не появятся.
- `rmdir /s /q %USERPROFILE%\OneDrive` удаляет папку вместе с локальными файлами.
- Deploy.cmd (из Master) — урезанная версия Start.cmd (нет этапов 2, 5–10).
